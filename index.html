What works now

A smaller set of features we can explain truthfully.

NakNak's current release focuses on reliable local safety actions and narrowly scoped family status sync.

☎
Direct emergency calling

NakNak opens the device dialer for a saved primary contact or emergency number. Carrier coverage still determines whether the call connects.

✓
Ayos Ako check-ins

Check-ins save on the phone. When a paired family connection is available, the dashboard is updated only after the server confirms delivery.

!
SOS-opened status

Opening SOS is recorded locally and can update the paired dashboard. It does not claim that a push notification, SMS, or automatic call was sent.

◷
Medication reminders

Schedules and notification reminders live on the device when notification permission is granted.

♿
Accessible controls

Large touch targets, clear contrast, reduced-motion support, and needs-based guidance are built into the Senior/PWD flow.

⌁
Offline-first essentials

Contacts, medications, profile settings, and local events remain available on the installed native app without relying on a live connection.

How it works

Simple for the person using it. Clear for the family supporting them.

Trust before features

NakNak should never pretend help is on the way.

A safety product is only useful when its interface is honest about what happened.

Designed to preserve dignity

The Senior/PWD experience prioritizes large familiar actions, readable language, minimal decisions, and direct calling. Caregiver management is intentionally separated from the emergency home.

FAQ

Clear answers before you rely on NakNak.

Is NakNak already on the App Store or Google Play?

Not yet. The repository includes an Expo/React Native native app, but public store release still requires signed production builds, privacy disclosures, physical-device testing, store assets, and approval.

Does SOS automatically contact my family?

Not in the current native milestone. NakNak records SOS locally and, when paired and online, can confirm SOS-opened status in the caregiver dashboard. Remote push, SMS, and automatic calling are not yet implemented.

Does medication reminder work offline?

Medication schedules are stored on the phone. On-device reminders can work without internet after notification permission is granted and the reminders are successfully scheduled.

Does NakNak track location?

The current native milestone does not automatically share location with caregivers. NakNak should not present location as delivered until that capability is implemented and explicitly consented to.

Where should caregivers go?

Caregiver / Anak tools belong in the authenticated Family Dashboard on the web. The native mobile app is being simplified around the Senior/PWD user.
