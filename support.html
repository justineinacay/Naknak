Common questions

My Ayos Ako status says it was saved locally.

The check-in is stored on the phone first. It is shown as delivered to the family dashboard only when the paired server connection confirms it.

Why didn't my caregiver receive a push notification?

Remote caregiver push notifications are not implemented in the current native milestone. The supported connected status is limited to Ayos Ako and SOS-opened updates in the dashboard.

My medication reminder did not appear.

Check that notifications are allowed for NakNak and that the reminder was scheduled successfully. Local reminders rely on the phone's notification system.

Can NakNak call automatically?

No. The current app opens the phone dialer when the user chooses a contact or emergency number. The user and operating system remain in control of the call.

Can I rely on NakNak instead of emergency services?

No. NakNak is a support tool. In an emergency, use the appropriate local emergency number and professional services.
