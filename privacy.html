Privacy & Data

This notice describes the current NakNak beta as implemented. It is written to make clear what stays on the phone, what can reach the caregiver dashboard, and which capabilities are not active yet.

Current privacy promise

NakNak should not present data as shared unless the app can genuinely confirm that sharing. The current native milestone does not automatically share location, send SMS, place automatic calls, or provide remote caregiver push notifications.

Data stored on the Senior/PWD phone

The native app may store the name and accessibility preferences entered during onboarding, emergency contacts, medication schedules, local reminder identifiers, check-in history, SOS-opened events, and the last check-in time. This data is stored locally so core safety information can remain available without a continuous internet connection.

Family pairing and dashboard sync

If the user chooses to pair the phone with a Family Code, NakNak stores an opaque device credential in secure device storage. The current native sync is deliberately narrow: it can report Ayos Ako and SOS opened status to the assigned Senior/PWD record in the authenticated Caregiver / Anak dashboard.

Medication schedules, emergency contacts, and automatic location are not part of that native sync milestone.

Caregiver account data

The web Family Dashboard uses authenticated household access backed by Supabase. Household data is intended to be restricted by database Row Level Security. A paired Senior/PWD phone does not receive a caregiver login session; its device credential is used only through limited server functions.

Notifications

Medication reminders are scheduled on the device when notification permission is granted. NakNak does not currently claim that caregiver push notifications are available.

Emergency calling

When the user chooses to call a saved contact or an emergency number, NakNak opens the phone dialer. The operating system and mobile carrier control whether a call can be completed. NakNak does not silently place automatic calls in the current release.

Location, sensors, and fall detection

The current native milestone does not automatically share the user's location with caregivers and does not implement fall detection. If these capabilities are added later, NakNak should request appropriate permission and update this notice before public release.

Payments

The web project includes payment infrastructure for future plan upgrades. Paid-plan activation should be based on verified payment events rather than a browser-only claim. Store-distributed digital features may also be subject to Apple and Google billing rules before public launch.

Resetting local app data

The Senior/PWD app includes a reset flow that clears local NakNak state and removes the local family device credential. If a device was disconnected while offline, a caregiver may still need to revoke the old paired device from the Family Dashboard.

Contact

For privacy or security questions, contact naknak@gmail.com. For security vulnerabilities, avoid posting sensitive details in a public issue.

Last updated: October 11, 2026. This beta notice should be reviewed again before App Store or Google Play submission and whenever NakNak's data handling changes.
